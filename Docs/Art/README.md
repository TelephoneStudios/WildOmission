# Art Reference

Store-page screenshots used as the style target for all new assets.

- Flat-shaded low-poly, no textures, one colour per material
- Warm saturated palette, blue-green nights with starfield sky
- Chunky ~8-sided prop silhouettes, faceted tree canopies
- Minimal HUD: pale rounded hotbar, thin green/blue/orange vital bars

See `Docs/ROADMAP.md` section 2 for the full asset rules.
